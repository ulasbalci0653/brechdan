# Brechdan – Premium Restaurant & Artisan Sandwich Website

Ankara Bahçelievler'de faaliyet gösteren **Brechdan** için geliştirilmiş modern, mobil uyumlu ve SEO odaklı resmi web sitesi.

---

## 🥪 Özellikler

- **%100 Doğrulanmış Menü ve Fiyatlar:** Retro Isırıklar (Dana Tiftik, Roast Beef, vb.), Yeşil Isırıklar (Hellim, Avokado, vb.), Kahvaltı Tabakları (Lokal, Soft, Grill), Tavadan Klasikler, Kabaran Omletler, Ekstralar ve İçecekler.
- **Marka Kimliği & Renk Paleti:** Brechdan'ın özgün orman yeşili, sıcak krem, adaçayı ve maskot turuncusu tonları.
- **İnteraktif Menü Deneyimi:** Anlık arama filtreleme, kategori sekmeleri ve vejetaryen/favori butonları.
- **Yerel SEO:** Google Restaurant Schema (JSON-LD) ve FAQPage Schema entegrasyonu.
- **Konum & İletişim:** Google Haritalar entegrasyonu, tek tıkla yol tarifi ve arama butonları.
- **Mobil Uyum:** Tek elle kullanıma uygun alt sabit hızlı erişim menüsü.

---

## 🛠️ Teknolojiler

- **Framework:** Next.js (App Router, TypeScript)
- **Styling:** Tailwind CSS
- **İkonlar:** Lucide Icons
- **Tipografi:** DM Serif Display & Plus Jakarta Sans

---

## 🚀 Başlangıç

Geliştirme sunucusunu başlatmak için:

```bash
npm install
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.

### Üretim Derlemesi

```bash
npm run build
npm run start
```
